# Sagar & Shrutika — Wedding Invitation (React + Tailwind + Framer Motion)

## Run
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in /dist
    npm run preview

## Customise
- ALL content: `src/data/weddingData.js` (dummy values are commented)
- Hero photo: save your Ballaleshwar Ganpati Temple, Pali image as `public/images/hero-temple.jpg`
- Photos: replace `public/images/g1..g8.svg`, `groom.svg`, `bride.svg` (or change paths in the data file)
- RSVP: set `rsvp.endpoint` (Formspree / Google Apps Script) to collect responses
- Deploy `dist/` to Netlify / Vercel / GitHub Pages
